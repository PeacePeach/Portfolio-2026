- research-insights.webp
- research-insights-full.webp
- lending-journeys.webp
- lending-journeys-full.webp
- account-ia.webp
- account-ia-full.webp
- payment-framework.webp
- payment-framework-full.webp

Use the standard image for the page and the `-full` version for the lightbox/high-resolution view.
